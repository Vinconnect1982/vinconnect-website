# VINCONNECT

Public website for [vinconnect.com.au](https://vinconnect.com.au) — Starlink installation, property Wi-Fi, wireless building links and CCTV across South East Melbourne, the Peninsula, Bass Coast and Gippsland.

Independent installer. Not Starlink, SpaceX, Circl, TP-Link or Hikvision.

## Stack

TanStack Start / React, Tailwind, Netlify.

## Local

```bash
npm install
npm run dev
```

Production canonical is `https://vinconnect.com.au`. `www` redirects to apex.

## Do not publish

Work orders, invoices, customer names or addresses, Circl CG/WO numbers, licence or insurance numbers, draft EventLink pricing, or VIN Gear Pulse specs that have not been confirmed.
